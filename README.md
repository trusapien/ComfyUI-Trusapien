# ComfyUI-Trusapien

Official ComfyUI custom nodes for [Trusapien](https://trusapien.com). Run creative campaign asset validation, predicted attention heatmaps, and impact scoring directly within your generation workflows.

> **Private Beta Notice**: The Trusapien API is currently in gated private beta. You can install this node today, but you will need an API key to execute live validation models. Request access at [trusapien.com](https://trusapien.com).

---

## Features

* **Creative Validation**: Test generated images against visual attention models before exporting assets.
* **Attention Heatmaps**: Identify where viewer focus lands within your image outputs.
* **Impact Scoring**: Evaluate creative assets against campaign objectives inside ComfyUI.

---

## Installation

### Method 1: ComfyUI Manager (Recommended)
1. Open **ComfyUI Manager** inside your ComfyUI interface.
2. Search for `ComfyUI-Trusapien`.
3. Click **Install** and restart ComfyUI.
